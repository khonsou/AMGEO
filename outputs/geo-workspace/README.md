# GEO 核心执行包

人的入口：[AM GEO](http://127.0.0.1:8787/)。

- `config/geo-playbook.json`：16 个中英候选问题，按找工具、找替代、怎么做、查事实分组；来源与方法链接一并记录。
- `state.json`：问题选择、11 项具体任务、真实产物哈希、检查与下一步、导入的访问聚合数据。
- `artifacts/`：默认 8 个交互工具页、最小结构化数据、爬虫策略与访问归因配置。页面为本地草稿，带 noindex，未发布。
- `checks/`：2026-11-04 读取的 robots.txt 与 .97 产品页原文、时间和哈希。网站与产品事实并未由本项目修改。

当前发现：商城 robots 规则允许目标公开路径；官网 robots.txt 返回 HTML，需在真实站点路由修复。产品页已有可解析的 Product 标记，先核对字段与正文，不重复叠加标记。真实爬虫 IP 的 CDN/WAF 通行与商品事实一致性尚待独立核验。

无 GA4 报表导入时，AI 会话和关键事件保持未知。支持带站点、日期的聚合 CSV；不保留原始 CSV，不跨导入文件累加，历史聚合快照保留。不把普通 Google、Direct 或爬虫请求猜作 AI 用户访问。

发布前先检查真实站点仓库与模板，核对具体型号、市场、当前数据；再把本地页面映射到实际路径，移除草稿 noindex，完成内部链接。此包不是已应用的站点源码或 Shopify 写入补丁。
