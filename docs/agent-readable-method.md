# AI 可读性：从案例到可验证改进

2026-11-11 采纳；执行规则见 [geo-knowhow.json](../config/geo-knowhow.json)。

Resend 的 Markdown 价格页和 llms.txt 已公开实现；访谈与推荐份额研究提供案例与假设，没有证明这些改造导致推荐份额提升。开发者工具的 Agent 选择，也不能直接外推为消费者对电竞鼠标和 AI device 的购买推荐。

先让正确事实可读取：产品型号、版本、市场、价格条件、兼容性与参数直接出现在 HTML 正文，图表中的关键数据提供文字等价。按实际需求提供直接答案与 FAQ；是否需要某字段取决于证据，AM Infinity .97 的 37g/39g 冲突继续隔离。有效 FAQ 不等于添加 FAQ schema。

围绕选购、替代、操作和事实形成有独立价值的内容。生成的问题是研究线索，先去重和合并主题，不强制一题一页。外部真实评测与使用经验比大量无依据提及更值得投入。

Markdown 与 llms.txt 是可选 Agent 入口，不能当作通用排名因素。若采用，从同一事实源自动生成；验证状态码、内容类型、实际正文和字段一致性，避免 HTML 兜底被误报为 Markdown。Google 的上述立场仅适用于 Google Search。

在优化 Todo 的「扫描 AI 可读正文、FAQ 与可选 Markdown」中点击「验证」。当前预设目标为海外 .97 产品页；后续其他型号必须使用已核实的实际 URL。扫描只报告原始 HTML 提取线索、数值差异与待复核项，不执行 JS，不模拟用户交互，不保证发现所有图表或隐藏内容，不证明事实正确。缺少可选文件不扣分；扫描通过只代表基础读取检查通过。

改动前后用相同题组和相同联网平台／设置重复采样，记录真实回答、最终引用 URL、推荐是否适配、事实是否正确和异常。保留对照问题与模型更新等影响，不用一次前后差异认定因果。未联网 DeepSeek API 保留为独立基线，不用于判断新页面的效果。

CDN／服务器中的抓取请求、AI 引荐人类会话、回答引用率、推荐率和事实正确率分别记录；抓取不等于访问或转化。完整日志仍在相应系统内，项目只接收必要的脱敏聚合数据。

证据链接与适用范围保存在配置的 `sources` 中；扫描结果保存实际执行时间，来源观察日期不会随扫描刷新。
