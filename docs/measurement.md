# 评分与改进的边界

本项目没有声称存在通用的 SEO/GEO 总分。不同观测对应不同问题，不合并成一个看似精确的品牌分数。

新增 `agent-readable-content-v1` 扫描，见 [可读性方法](agent-readable-method.md)。正文提取、FAQ 标题、Markdown 数值差异与 llms.txt 仅为诊断，缺少可选文件不扣 SEO / GEO 分。原始响应与执行时间保留；需逐字段事实复核。CDN 抓取日志、AI 引荐人类会话、回答引用、推荐和事实正确分别记录。网站改造需联网固定题组评估；未联网 API 命中不能验证新网页效果。

## 搜索表现

真实自然搜索表现需要相应平台数据或固定 SERP 面板。未接入时分数为 null；公开页面可访问、产物验收或关键词出现不能替代真实排名、展现、点击和流量。

`config/search-panel.json` 固定了 Bing 浏览器搜索的四条非品牌发现查询，覆盖中英鼠标与 AI device。分别计算每语言题组的“官方域名出现在前十条自然结果”的查询占比；这不是第三方文章中的品牌提及率或通用 SEO 分。保存原文、结果顺序、目的 URL、截图和哈希。广告、AI 摘要、视频/新闻模块排除；不足十条自然结果为覆盖错误，不能记零。

页面可能被重定向到 `cn.bing.com`，请求 en-US 不证明美国市场定位已生效。每条保留实际 URL、采集时间、补存截图时间和采集异常；未验证实际地区、个性化及设置一致时不标为可比。固定查询样本与 GSC/Bing/百度账号展现、点击和流量分别报告。

## 原始 HTML 技术诊断

`raw-html-technical-v1.1` 检查 3 个预设品牌公开页面：品牌首页、海外 .97 产品页和中文历史产品页。每页 6 项等权：HTTP 成功、非空 title、非空 description、唯一有效的绝对 canonical、非空 H1、未发现显式 noindex / none。非成功 HTTP 页不因错误页含标题而得分，网络错误另报、无有效检查则为 null。

分数为通过检查数 / 已执行检查数 × 100，并始终显示页面覆盖和错误。该内部规则不是 Google 的评分，不包含 JS 渲染、robots 完整解析、真实收录、核心网页指标、流量或转化。未发现 noindex 不表示已收录或一定可抓取。规则是用于发现问题的诊断，不是排名因果模型。

Google 对 AI 搜索的官方指导仍要求基础 SEO、可访问与有帮助的可靠内容；该来源不为本项目的 6 项权重或任何总分背书。[Google Search Central](https://developers.google.com/search/docs/appearance/ai-features)

## GEO 答案试运行

当前默认面板为 `config/answer-panel.json` 的 `core-discovery-answer-v1`：中英文各两题，每语言一题电竞鼠标、一题 AI device。固定模型 gpt-6.1-sol，独立临时工作目录、新进程及联网模式，不注入品牌定位或 TA。题组配置、模型、主题、哈希和原始结果随本次测量保存。

历史 `bilingual-discovery-pilot-v1` 固定题目 EN-M-02、EN-K-04、ZH-M-02、ZH-K-04；非品牌问题从版本化题库读取。固定模型 gpt-6.1-sol、联网模式、独立临时工作目录和新进程，避免品牌项目文件或上一题污染回答。每市场仅 2 题，小样本只用于流程试运行。

保存原始回答、最终回答引用 URL、搜索调用轨迹、问题、语言、模型、时间及错误。品牌出现率由正文匹配 Angry Miao / 怒喵计算，100 × 出现次数 / 完成测试数；无 AI 回答计零，错误单报。官方引用率仅作诊断，不是品牌成功的唯一目标。没有独立证据时不推断推荐适配或事实正确率。

这是 Agent/API 联网回答，不是 ChatGPT、Gemini、豆包消费端基线。面板题目、模型与口径生成 fingerprint；前后样本必须可比才可讨论观测变化。一次分数变化不证明优化导致提升。新核心题组与旧鼠标/客制化键盘题组不能比较升降；旧观察保存在轮次的 measurement 目录和 metrics-history 中。

## Know-how

执行过程经验与效果假设分别保存，并关联轮次、任务或评估字段。策略版本增加表示下一轮使用了新的方法候选，不表示其效果已获证明。不能删难题、合并平台、降低验收或选择性丢弃失败样本来提高分数。

Agent 调用依照本机 CLI 实际支持的结构化输出、只读模式及超时执行。[OpenAI 官方非交互运行说明](https://learn.chatgpt.com/docs/non-interactive-mode)
