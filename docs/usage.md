# 使用 AM GEO

打开 [工作台](http://127.0.0.1:8787/#todo)。

- **优化 Todo**：按网站基础、内容与工具页、AI 流量归因分组。勾选表示执行已完成，验证结果独立显示“待验证 / 通过 / 不通过”。展开任务即可准备产物、查看步骤、预览和验证。AI 流量来源设置与聚合报表导入也在对应 Todo 内。
  网站基础中的「扫描 AI 可读正文、FAQ 与可选 Markdown」点击「验证」即可执行公开页面扫描，无需 API key。基础检查与建议／待复核项分开显示，可选文件缺失不扣分，不自动修改站点。
- **问题测试**：输入公开的产品与场景，点击“生成并测试 8 题”。Skill 按找工具、找替代、怎么做、查事实生成中英问题，分别调用独立 API 回答并计算品牌 / 产品命中。可展开每题原始回答；选中问题可生成优化 Todo。
- **GEO 评分浮窗**：右下角展开。新 API 测试与历史联网 Agent 分别显示；发现题和含品牌的问题分开计分。用“重测原题组”保持问题不变。
- **Settings**：API 连接、品牌资料、历史任务、原始证据和策略。模型与 Base URL 可见，key 不回显；本机 Keychain 可用时安全保存，否则仅保留于进程内存。

勾选不会自动证明发布或抬高 GEO 分。空回答计零，调用错误与未运行题分别记录。DeepSeek 基础 API 回答未联网；一次命中不代表推荐适配、事实正确或消费端搜索表现。修改题组或请求协议后不可直接比较分数。

工具与配置可在本地准备，真实站点发布仍需源码 / CMS 连接。AI 流量没有报表时保持未知。工作台不安装无限循环或定时收费任务，每次模型测试由点击启动。

服务停止或电脑重启后，由维护 Agent 恢复；维护信息见 [development.md](development.md)。
