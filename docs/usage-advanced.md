# 使用 AM SEO 优化循环

打开 [AM SEO 工作台](http://127.0.0.1:8787/)。日常操作在这个 URL 内完成，不需要复制交付物、输入命令或回聊天触发执行。

## 1. 开始分析

点击首页的“开始分析”。默认覆盖 Angry Miao 中英文市场；展开“调整本轮目标与市场”可更改关注点和渠道。首页的品牌与 TA 卡片显示当前定位、三类人群及资料版本。每轮标明实际采用的版本；旧轮如显示“未采用”或“已更新”，保留原结果，重新分析才能使用新资料。

这会实际调用本机已登录的 Codex Agent，按当前策略、品牌事实和锁定的开源方法资料搜索公开信息，并生成本轮任务。页面显示运行状态和错误，完成后显示发现、来源及任务。若账号额度、网络或运行时不可用，显示失败并保存记录，不会把提交当作分析完成。

## 2. 执行任务

在“执行任务”中查看每项任务的负责人、操作说明、来源、前置条件和验收标准。

- **Agent 任务**：点击“执行任务”，或用“执行可运行任务”运行当前可执行项。每批最多执行 3 项，其余保留。研究与内容任务会产出实际文件，并附在任务卡中。也可点击“执行一批并复盘”，依次执行、独立核验、评估与更新策略；只有前置任务核验通过，才继续依赖它的任务。
- **人类任务**：用于需要品牌决定、实物测试或特定访问范围的事项。完成后在任务卡内提交结果和来源，进入核验。
- **等待条件的任务**：显示缺失连接或前置任务；独立任务仍可继续。普通研究与写稿不会因为缺少发布权限而全部转给人。

当前执行器准备公开研究与本地产物，不直接修改线上站点、商城或向第三方发送消息。

## 3. 查看和验收结果

点击任务下的产出即可读取正文，Agent 已直接使用项目文件，不需要你复制粘贴。点击“Agent 核验产物”，由新的独立 Agent 运行按原条件与来源逐项核验。通过后标记本地产物完成；不通过则保留具体问题并返回可修改状态。团队也可以独立核实后填写依据，选择“验收通过”或“退回修改”。

执行者自检、文件完整性检查、独立验收分别记录。验收通过只确认本轮任务产物，不表示已发布或已带来搜索提升。前置任务验收后，可继续执行依赖它的任务。

“资料库”保存策略参考、产品事实、题库和历史成果，作为任务输入与证据；它不是主待办列表。

## 4. 评估本轮

点击“评估本轮”，系统执行当前已接入的测量，并保留已导入搜索证据的原始采集时间：

- **SEO 搜索表现**：支持 Agent 导入固定四条非品牌查询的 Bing 浏览器记录，按中英文题组计算官方域名进入自然结果前十的占比。展开记录可查看查询、结果顺序、链接、截图及错误；不足十条自然结果记覆盖错误。没有真实搜索证据时显示“待测”。页面保留实际搜索域名与设置限制：重定向到 `cn.bing.com` 的英文查询不能直接视为美国市场排名；搜索账号的展现、点击和流量单列，未连接时保持待测。“评估本轮”不会自动重新采集这些浏览器记录。
- **SEO 技术诊断**：重新采集 3 个品牌公开页面，按 6 项等权的内部 HTML 检查计分，显示覆盖范围与采集错误。不执行页面 JavaScript，这个分数不代表排名、收录或流量。
- **GEO 试运行面板**：默认 `core-discovery-answer-v1` 固定 4 道非品牌问题，中英文各一题电竞鼠标、一题 AI device；每题在无品牌文件的独立 Agent 会话中联网回答。分别报告两个语言题组的品牌出现率、官方引用、样本和错误，不合成总分。展开记录可查看原始问题、回答、引用、模型和采样时间。它是 Agent/API 回答试验，不代表 ChatGPT、Gemini、豆包等消费端界面表现，也不证明推荐适配或产品事实正确。旧鼠标/客制化键盘试运行保留为历史记录，不能与新题组直接比较升降。

无 AI 回答计入完成测试分母，调用错误另报。没有样本时显示“待测”而不是零分；每语言仅 2 题只能作为小样本诊断，不代表整个地区市场。完整定义见 [评分口径](measurement.md)。

## 5. 复盘并开始下一轮

点击“复盘并更新策略”。Agent 根据本轮任务状态和实际评估记录，保存带来源的执行方法候选与待验证假设，形成下一版策略。

随后点击“按新策略开始下一轮”。新分析会读取策略版本、经验和上一轮结果，并重新生成任务。方法版本增加不等于品牌效果提升，效果需要同题组、同平台、同模型与设置下的可比观测。

循环由每次点击启动，没有安装无人值守的无限循环或定时任务。使用当前 Codex 登录态，会消耗相应账号的可用额度；页面失败信息会保留具体原因。

## 页面不可用时

这个 URL 当前只在运行服务的电脑上可用。服务停止或电脑重启后，由维护 Agent 恢复；不需要日常使用者操作 CLI。维护信息见 [维护说明](development.md)。

## 模型调用受限时

页面会保留上次额度或认证错误，停止自动重复调用。已保存产物、人工结果与验收、资料检查和“网站技术检查”仍可使用。技术检查会新采集公开页面，GEO 若显示旧结果会保留其原时间，不冒充本次新采样。

可点击“已有证据本地复盘”，从任务、错误与评估记录提炼执行方法候选。该步骤由本地规则完成，不调用模型、不新增搜索，也不声称效果提升；下一轮可读取该策略候选。

实际恢复额度或登录后，点击“额度恢复后，重试 Agent 连接”。这是一次明确的最小模型连接检查；通过后再启动所需步骤，不会自动更换账号、模型或计费通道。
